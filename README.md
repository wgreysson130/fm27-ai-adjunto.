# FM27 AI Adjunto

Aplicativo web instalável para celular e tablet. Versão inicial com respostas locais, sem IA conectada.

## Publicação
Envie os arquivos deste diretório para um repositório próprio no GitHub. Na Vercel, importe esse repositório, escolha framework **Other**, sem comando de build, e publique.

## Limitações
A análise real de prints e o chat com IA exigem backend seguro e integração com API. O arquivo HTML sozinho não faz análise de imagem. Os dados são armazenados apenas no navegador.
